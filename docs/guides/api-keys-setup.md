# API Keys Setup (Gemini and OpenAI)

## Where to configure in physics-IDE

1. Open Customize menu.
2. Go to Location tab for paths and project context fields.
3. Go to AI/Providers tab to paste provider keys and select models.
4. Save configuration.

## Gemini API key

1. Open Google AI Studio from your browser and create an API key.
2. Paste the key into the Gemini key field in settings.
3. Select Gemini for left or right lane provider as needed.

## OpenAI API key

1. Open the OpenAI platform dashboard and create an API key.
2. Paste the key into the OpenAI key field in settings.
3. Select OpenAI for left or right lane provider as needed.

## Verification checklist

1. Save settings.
2. Send a short test prompt in each lane.
3. Confirm responses appear without provider errors.

## Security note

Keys are local to your device configuration. Rotate keys if exposed and avoid sharing screenshots with visible secrets.
