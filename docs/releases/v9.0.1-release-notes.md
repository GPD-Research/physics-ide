# v9.0.1 Release Notes

Patch release. It fixes a basic flaw in Task mode that the alpha_Y benchmark stress test
exposed: a model could write placeholder code, run it, report the output and declare `<<<DONE>>>`.
It also ships the long-run Local AI and system-monitor work.

## Changes

- **Task mode DONE gate.** A `<<<DONE>>>` is checked before the task is accepted. The task goes
  back to the model, with the reasons, if any of these is true:
  - a file it wrote during the task still contains `TODO` / `FIXME` / placeholder / stub code;
  - a written report has a `RESULT:` line that no `RUN`/`CALC` output printed;
  - the task asked for `RESULT: name=value±err` and some lines have no error.

  After two send-backs the task ends as **done (unverified)** and the remaining problems are
  listed in the terminal log. The task protocol prompt states these rules up front.
- **Local AI long runs (#38).** Ollama replies stream, and there is no longer a total time cap.
  A reply is abandoned only after the **Local AI silence limit** (Settings, default 60 min).
  While a reply is in progress the pane shows live `reading prompt` / `writing N tok · tok/s`
  progress. Stop cancels the request. Timeouts, a missing Ollama, and an Ollama crash each get
  their own error message.
- **View ▸ Monitors (#37).** CPU, Memory and System (conky-style, including the Ollama process)
  floating windows. They poll once a second, and only while they are open.
