# v9.0.2 Release Notes

Patch release with two fixes found during the alpha_Y Task-mode benchmark.

## Fixes

- **Cloud chat replies are no longer cut off after 20 s (#41).** OpenAI and Gemini chat requests
  had a 20-second limit on the whole request, so any Task round that took longer failed. Rounds
  that write a whole script after reading several files usually do. The error was a bare
  `error sending request for url (…)`. Connecting is still limited to 20 s, but a reply can now
  take up to 15 min. Request errors now say what went wrong: a timeout, a refused connection,
  DNS, or TLS. Validation calls keep the 20 s limit.
- **Settings ▸ Theory Source File is saved (#40).** This path was never stored, so it had to be
  selected again on every launch. It is now saved with the other location paths.
